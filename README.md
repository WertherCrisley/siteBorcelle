# 🛍️ Borcelle

**E-commerce de moda feminina desenvolvido para estudos de Front-End**

Projeto de uma loja virtual de roupas femininas desenvolvido com o objetivo de praticar e aprimorar conhecimentos em **desenvolvimento web, interfaces responsivas, componentes e interações com o usuário**.

O projeto simula uma experiência de e-commerce, permitindo visualizar produtos, selecionar opções e interagir com um carrinho de compras.

## 📸 Sobre o projeto

A Borcelle foi desenvolvida como um projeto de estudos para colocar em prática conceitos de desenvolvimento Front-End e criação de interfaces para aplicações de comércio eletrônico.

O projeto possui uma interface voltada para moda feminina, com foco em organização visual, navegação e experiência do usuário.

### ✨ Funcionalidades

* 🛍️ Catálogo de produtos
* 🔎 Busca de produtos
* 🛒 Carrinho de compra
